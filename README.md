# Portfolyo sitesi (React + Vite)

İçerik: **`src/content/site.ts`**

## Yerelde çalıştırma

```bash
npm install
npm run dev
```

## GitHub Pages ile yayınlama

Adımlar: **[deploy/GITHUB-PAGES.md](./deploy/GITHUB-PAGES.md)**

1. Repoyu GitHub’a push et.
2. **Settings → Pages → Source: GitHub Actions**
3. Birkaç dakika sonra site hazır.

- Repo adı `kullanici.github.io` → `https://kullanici.github.io/`
- Repo adı `portfolio` gibi → `https://kullanici.github.io/portfolio/`

Özel domain: `public/CNAME` + Pages ayarından domain ekle.

## Diğer notlar

VDS / aaPanel rehberleri `deploy/` altında duruyor; kullanmıyorsan yok sayabilirsin.
